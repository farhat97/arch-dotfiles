# Arch (btw) and Hyprland setup

## Required software
- waybar
- fuzzel
- swaync (might need to disable existing notification daemon if using `archinstall`)
- rofi

### Some misc required software (that I can remember)
- qt6ct
- bluetoothctl
- btop
- flameshot

## Qt6 settings for Breeze Dark color scheme
- Add the following line under /etc/environment : 
`QT_QPA_PLATFORMTHEME=qt5ct`
